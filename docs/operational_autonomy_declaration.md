# KnowledgeForge Operational Autonomy Declaration

Date: 2026-07-09
Status: authoritative operational declaration
Classification: preserves agreed architecture

## Declaration

KnowledgeForge is operationally autonomous for ordinary Operational Expansion production campaigns.

Campaign-by-campaign external prompting is complete. Future production progression should derive from:

1. `CONSTITUTION.md`;
2. `docs/production_doctrine.md`;
3. `docs/production_campaign_roadmap.md`;
4. `docs/production_evolution_log.md`;
5. family closeout reports and Production Methodology Closeout reports;
6. current state and latest handoff files.

The roadmap is the authoritative source of future production sequencing. The Production Doctrine is the authoritative source of production execution mechanics.

## Default operating rule

Unless a Doctrine Review Trigger occurs, the correct next action is to continue the roadmap automatically:

1. execute the next campaign;
2. validate packages;
3. populate the Knowledge Repository;
4. produce required governance and repository-value artifacts;
5. update the Production Evolution Log;
6. assess family maturity;
7. continue with the same family until Mature;
8. move to the next roadmap family.
