## Why Pearson residue is not priority evidence

Campaigns 42-43 already established the important infrastructure facts:

- raw and first-difference packages can coexist;
- paired production is architecture-compatible;
- transformed results can qualify raw relationships;
- retrieval and export can distinguish raw and transformed methods.

Therefore the remaining Pearson candidates must compete on marginal knowledge value, not on proving the pattern again or exhausting an eligible list. Eligibility does not create production obligation.

## Mandatory comparison outcome

### B. Paired NOR demographic/health Pearson preparation

Rejected for immediate priority.

The three NOR pairs are semantically close and technically feasible, but their marginal knowledge value is low-to-medium. They are concentrated in one country and one demographic/health cluster, are likely dominated by shared development/time trends, and would probably repeat Campaigns 42-43's lesson that level correlations weaken or need qualification after differencing. Strong first-difference results would be useful objective leads but still narrow. Near-zero first-difference results would mostly add another instance of an already-established robustness pattern.

### C. Bounded WDI Nordic exports-share statistical-summary replication

Rejected as a next task because it is already complete in the current canonical repository.

Campaign 35 accepted exactly the proposed three packages:

- `pkg-object-srcpkg-campaign35-dnk-exports-share-statistical-summary-v2`
- `pkg-object-srcpkg-campaign35-swe-exports-share-statistical-summary-v2`
- `pkg-object-srcpkg-campaign35-nor-exports-share-statistical-summary-v2`

The method, retained evidence, per-entity summary statistics, and canonical packages already exist. Re-running the same replication would mainly duplicate existing knowledge unless framed as a no-new-package regression/reproducibility check, which is verification value rather than new production value.

### D. Non-WDI multi-source disagreement planning gate

Selected.

This is the strongest documented alternative because PEL-017/non-WDI multi-source disagreement remains a repeatedly documented falsification gap after multiple WDI families reached Mature status. Unlike B, it tests a new epistemic boundary rather than adding another narrow Pearson cluster. Unlike C, it is not already completed in canonical packages. It is production-enabling rather than production, but the expected value is high: it can determine whether KnowledgeForge can represent objective source disagreement without slipping into interpretation or requiring architecture redesign.

## Final Pearson candidate dispositions

### NOR crude birth rate / under-5 mortality

Disposition: defer indefinitely; do not include in the next task.

Raw package value: finite-window level co-movement between two close demographic/health indicators. This is not a duplicate package, but much of the relation is predictable from shared demographic transition and development trends.

First-difference package value: could show whether annual changes co-move after trend removal. A weak result would mostly repeat Campaigns 42-43's qualification pattern; a strong result would be reusable objective evidence but still narrow and likely an InsightForge analytical lead.

### NOR crude birth rate / life expectancy

Disposition: defer indefinitely; do not include in the next task.

Raw package value: finite-window level co-movement between fertility/birth-rate structure and survival conditions. Useful only modestly because the relationship is expected from broad demographic transition.

First-difference package value: possible year-to-year co-movement evidence. The expected interpretive burden is high, and a nonzero result would still require careful downstream analysis outside KnowledgeForge.

### NOR crude death rate / under-5 mortality

Disposition: defer indefinitely; do not include in the next task.

Raw package value: finite-window level co-movement between mortality indicators. This is close to mechanically/structurally related and overlaps the demographic/health cluster already represented by existing packages.

First-difference package value: could bound whether the mortality indicators move together annually, but it risks overweighting one country and one tightly connected cluster.

### DNK forest area / private credit

Disposition: reject for current production priority; may remain as archived policy residue only if future pressure-test work explicitly needs remote cautionary pairs.

Its semantic relationship is remote, time-risk is high, coverage is slightly below full, and expected value is mainly cautionary. It should not be produced merely because it is eligible.
