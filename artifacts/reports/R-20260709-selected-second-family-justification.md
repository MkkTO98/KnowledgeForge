# Selected Family Justification — WDI Environment Annual-Scalar Evidence

Date: 2026-07-09
Status: completed

## Selected family

WDI Environment annual-scalar evidence.

## Justification

The selection maximizes production learning because it tests whether the mature WDI demographic methodology transfers to a materially different evidence family while preserving the same external source family, annual-scalar shape, deterministic construction pattern, package model, validator path, provenance model, and reporting standard.

Environment is the strongest choice because it introduces:

- non-demographic indicator-family semantics;
- different inventory labels and evidence-quality patterns;
- likely different missingness/coverage structures;
- future cross-family comparison opportunities against demographic evidence;
- enough indicator breadth for maturation without immediate scale overload.

## Why this is not domain selection

Environment is not chosen because environmental knowledge is economically important. It is chosen because it is the best controlled cross-family transfer test under the existing KnowledgeForge production methodology.

## Expected unresolved PEL contribution

- PEL-012: Environment alone will probably still use single-reference accepted objects in Campaign 8, but it enables Campaign 9 cross-family objects with multiple evidence references.
- PEL-017: Environment tests cross-family transfer and may later support overlapping valid objects and partial disagreement conditions.
- PEL-018: It tests whether the maturity pattern from the demographic family can become a repeatable production-family maturation method.
- PEL-020: It will test whether provenance-lineage completeness remains representation-neutral outside the demographic family.
